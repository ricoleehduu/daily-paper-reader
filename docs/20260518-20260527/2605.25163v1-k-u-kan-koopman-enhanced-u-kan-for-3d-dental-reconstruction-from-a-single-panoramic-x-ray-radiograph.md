## 摘要
全景 X 光片将三维颌骨压缩为二维带状图像；我们旨在干净、快速地恢复缺失的深度信息。现有的隐式神经表示能生成逼真的体积，但训练缓慢，对采样和位置编码敏感，且在实际应用中成本高昂。纯 CNN 基线方法效率较高，但在处理牙弓的长程几何结构时存在困难，会模糊牙釉质与牙本质之间的精细边界，且可解释性差。我们提出了 K-U-KAN，一种三阶段流程：(i) 使用 Kolmogorov-Arnold 网络将二维特征提升为深度感知的可观测量；(ii) 通过 Koopman 令牌块以稳定、相位感知的线性演化推进这些可观测量；(iii) 将预测的深度区间置于聚焦槽射线上，之后由轻量级三维注意力 U-KAN 细化体积。这种物理（比尔-朗伯成像模型）、几何（马蹄形聚焦槽）与学习的线性动态的结合，产生了清晰的解剖结构、更少的伪影，并在批大小为 1 的原始放射强度下表现出稳健的行为。在留出测试数据上，K-U-KAN 在信号和结构指标上与基于 Transformer 或隐式表示的基线方法相当，明显改善了感知质量，且训练时间大约只有一半——使得单视图全景 X 光到锥形束 CT 的重建在临床流程中更加实用。

## Abstract
A panoramic X-ray compresses a 3D jaw into a 2D strip; we aim to recover the missing depth cleanly and fast. Existing implicit neural representations render realistic volumes but are slow to train, sensitive to sampling and positional encodings, and costly in practice. Pure CNN baselines are efficient yet struggle with the dental arch's long-range geometry, blur fine enamel-dentin boundaries, and offer little interpretability. We present K-U-KAN, a three-stage pipeline that (i) lifts 2D features into depth-aware observables with Kolmogorov-Arnold Networks, (ii) advances these observables by a stable, phase-aware linear evolution via a Koopman token block, and (iii) places the predicted depth bins onto focal-trough rays before a lightweight 3D attention U-KAN refines the volume. This marriage of physics (Beer-Lambert image formation), geometry (horseshoe focal trough), and learned linear dynamics yields sharp anatomy, fewer artifacts, and robust behavior on native radiographic intensities with batch size one. On held-out data, K-U-KAN matches transformer/implicit baselines on signal and structure metrics, clearly improves perceptual quality, and trains in roughly half the time-making single-view PX $\to$ CBCT reconstruction more practical for clinical pipelines.

## 2. 方法论
- **整体框架**：K-U-KAN 是一个三阶段重建流程：
  1.  **KAN 提升（Lift）**：用 Kolmogorov-Arnold 网络（KAN）将二维特征图中每个像素的特征映射为“深度感知观测量”。
      - KAN 将可学习的一维样条函数置于网络边缘上，取代传统固定激活函数，使非线性建模更灵活且可解释。
  2.  **Koopman 令牌动态演化**：对提升后的观测量施加一种稳定、相位感知的线性演化。
      - 基于 Koopman 算子理论，将测量量沿其近似特征方向进行收缩与旋转（收缩因子 \(|λ_d|<1\)，旋转相位 θ\_d），并附加一个幅度有界的自适应门控校正。
      - 该步骤既能防止数值发散，又为长程牙弓曲率提供了一种“相位载体”，实现深度分配的一致性。
  3.  **焦点槽逆弯曲与三维细化**：
      - 将预测的 K 个深度区间（flat depth field）沿预计算的非交叉椭圆聚焦槽射线（horseshoe focal trough）反向映射，生成初始种子体积 \(V^{(0)}\)。
      - 用带注意力门控和 KAN 瓶颈的三维 U-Net（3D Attention U-KAN）对种子体积进行细化，恢复牙釉质-牙本质边界、皮质骨边缘等细节。
- **损失函数**：组合损失 = 体素级均方误差（MSE）+ 多视图最大强度投影（MIP）损失 + 基于 VGG-16 的多层感知损失。λ 权重平衡各项。
- **关键技术细节**：KAN 边函数用 B 样条实现；Koopman 更新通过两个实数层面的逐元素乘积和一个小的线性投影完成；轴向自注意力以 \(O(HWC(H+W))\) 复杂度捕获全局上下文。

## 6. 主要结论与发现
- **质量与效率平衡**：K-U-KAN 在 PSNR（23.42 dB）和 SSIM（74.86%）上与最强的 ViT-NeBLa 基本持平，但 LPIPS 感知质量显著更优（VGG 0.3212 vs 0.4204），同时训练时间缩短约一半。
- **模块有效性**：消融表明，注意力 3D U-KAN 细化模块可进一步提升感知锐度（降低 LPIPS），且几乎不增加训练成本。
- **物理-几何-动力学融合**：结合比尔-朗伯成像模型、马蹄形聚焦槽几何和 Koopman 线性演化，实现了在原生强度范围内稳定、无背景条纹伪影的重建，并改善了牙根管连续性和皮质骨细节。
- **实用潜力**：在良好重建质量下大幅缩减训练与推理时间，为单张全景片驱动的三维牙科规划提供了更切实可行的途径。

## 7. 优点
- **创新架构**：首次将 KAN 与 Koopman 算子结合用于医学体积重建，利用“测量量的线性演化”对深度病态问题进行正则化，兼具物理直观性与可解释性。
- **几何显式建模**：采用非交叉的椭圆形聚焦槽射线，避免隐式方法中因射线交叉产生的密度平均化和信息模糊，提升了边界清晰度。
- **高效训练**：摒弃点状采样和繁琐的渲染循环，以栅格化卷积为主干，在极少增加参数的情况下实现显著加速，批尺寸 1 下仍保持稳定。
- **感知优先**：损失函数中引入多视图投影和 VGG 感知损失，使重建结果在视觉上更接近临床所需的真实解剖纹理。

## 8. 不足与局限
