## 摘要
医学图像分割在持续学习中面临一个根本挑战：数据从异构源顺序到达，而有效的持续学习需要发现哪些任务共享足够结构从而受益于联合学习。现有方法要么在所有任务上施加统一约束，当任务冲突时导致灾难性遗忘，要么需要无法预见未来任务多样性的预定义任务分组。我们提出了MedCRP-CL，这是一个执行在线任务结构发现和结构感知持续学习的框架。利用中餐馆过程（CRP），我们的方法在任务到达时从临床文本提示中动态推断任务分组，无需预定义的聚类数量或访问未来任务。我们将这些发现的分组称为语义模态，因为它们通过整合解剖区域和病理上下文捕捉了比物理成像模态更细粒度的结构。以这种发现的结构为指导，我们维护语义模态特定的LoRA适配器，并通过模态内EWC进行正则化，确保不同任务组之间的参数隔离，同时促进相似组内的知识迁移。该框架也是无回放的，只存储聚合统计信息而非原始患者数据。在四个成像模态的16项医学分割任务上的实验表明，MedCRP-CL实现了73.3%的Dice分数，仅有4.1%的遗忘，比最佳基线高出8.0%，同时所需参数量仅为1/6。代码可在 https://github.com/zygao930/MedCRP-CL 获取。

## Abstract
Medical image segmentation faces a fundamental challenge in continual learning: data arrives sequentially from heterogeneous sources, yet effective continual learning requires discovering which tasks share sufficient structure to benefit from joint learning. Existing methods either apply uniform constraints across all tasks, causing catastrophic forgetting when tasks conflict, or require predefined task groupings that cannot anticipate future task diversity. We introduce MedCRP-CL, a framework that performs online task structure discovery and structure-aware continual learning. Leveraging the Chinese Restaurant Process (CRP), our method dynamically infers task groupings from clinical text prompts as tasks arrive, without requiring predefined cluster counts or access to future tasks. We term these discovered groupings semantic modalities, as they capture finer-grained structure than physical imaging modalities by integrating anatomical region and pathological context. Guided by this discovered structure, we maintain semantic modality-specific LoRA adapters regularized by intra-modality EWC, ensuring parameter isolation across dissimilar task groups while facilitating knowledge transfer within similar ones. The framework is also replay-free, storing only aggregate statistics rather than raw patient data. Experiments on 16 medical segmentation tasks across four imaging modalities demonstrate that MedCRP-CL achieves 73.3% Dice score with only 4.1% forgetting, outperforming the best baseline by 8.0% while requiring 6$\times$ fewer parameters. Code is available at https://github.com/zygao930/MedCRP-CL.

### 2. 方法论：核心思想与关键细节
- **核心思想**：将临床文本提示（prompt）作为任务结构发现的线索，利用 **贝叶斯非参数聚类**（中国餐馆过程，CRP）动态推断任务分组，再为每个分组（语义模态）维护独立的低秩适配器（LoRA），并用**模态内弹性权重巩固（EWC）** 防止同一模态内任务间的遗忘。
- **关键技术细节**：
  - **语义模态发现**：每个任务的所有文本提示经过冻结的 CLIP 文本编码器 `ϕ` 得到归一化嵌入 `e_t`。维护每个已有模态 `k` 的运行质心 `μ_k`。利用 CRP 作为先验：
    - `P(z_t = k | z_{1:t-1}, α) ∝ n_k` （已有簇）
    - `P(z_t = new) ∝ α`
  - **自适应相似度分布**：在线估计同一模态内部相似度和跨模态相似度的高斯分布参数，并用韦尔福德算法更新。似然项 `ℓ(s_{t,k})` 基于这两组分布的差异，确保分配由嵌入相似度决定。
  - **后验分配**：通过 MAP 推断选取后验概率最大的已有模态或新建模态。
  - **语义模态特定 LoRA**：为每个发现的语义模态分配独立的 LoRA 调整参数（秩 `r=8, α=16`），应用于视觉和文本编码器中的注意力投影层。跨模态参数完全隔离，同模态内共享。

### 6. 主要结论与发现
- MedCRP‑CL 在 16 项异构任务上取得 **73.3% 平均 Dice**，仅 **4.1% 遗忘**，比最佳基线 MoE‑Adapters 高出 8.0%，参数量只是其 1/6。
- 自动发现的 5 个语义模态（心脏超声、内窥镜息肉、皮肤镜、胸片、乳腺超声）比物理成像模态（4 类）更细粒度，成功将心脏超声与乳腺超声分离，降低了模态干扰。
- 模态内 EWC 有效抑制同一模态内任务的遗忘，而 CRP 驱动的参数隔离避免了跨模态冲突，且无需重放历史数据。
- 方法对任务顺序不敏感，对不同文本编码器和一定程度的提示噪声具有鲁棒性。

### 7. 优点
- **无监督结构发现**：无需预定义聚类数或任务标签，自动从提示嵌入中学习语义组织结构。
- **隐私友好**：纯统计量存储，无回放原始数据，符合 HIPAA/GDPR 要求。
- **高效性与强性能**：仅 8.6M 可训练参数，远低于 MoE‑Adapters 的 51.9M，且分割精度和抗遗忘能力显著优于基线。
- **理论与实验结合**：给出聚类一致性和模态隔离遗忘上界的理论保证，并进行了详尽的消融和鲁棒性实验。
- **嵌入鲁棒性**：对多种视觉–语言预训练编码器和提示扰动具有良好的适应能力。

### 8. 不足与局限
- **任务类型限制**：仅考察 2D 分割任务，未扩展至 3D 体积数据或多标签场景。
- **依赖文本提示**：需要为每个任务提供临床文本描述，且极度依赖 CLIP 风格对比学习文本编码器的嵌入质量；非对比训练编码器（如 SigLIP、PubMedBERT）会失效。
- **CRP 浓度参数**：α 固定为 5.0，虽在多种编码器下鲁棒，但在极端情况可能需要调优。
- **数据多样性**：虽覆盖 4 种成像模态，但均来自公开数据集，与真实临床流数据（多中心、低质量标注、概念漂移）尚存差距。
- **计算开销**：存储多个 LoRA 适配器和 Fisher 矩阵，任务数极多时可能带来存储压力；同模态内 EWC 正则化强度 λ 需预先设定，未实现自适应。
