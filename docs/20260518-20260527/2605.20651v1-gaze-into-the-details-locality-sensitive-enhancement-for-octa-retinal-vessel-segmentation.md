## 摘要
现有的用于光学相干断层扫描血管造影（OCTA）血管分割的深度学习框架大多源自U-Net架构，该架构是当前大多数设计的基础。然而，这些方法大多只关注整体表示，难以解决OCTA特有的低局部对比度问题，这会导致血管不连续和细节丢失。为解决这些问题，我们提出了LSENet，它在U-Net架构基础上引入了三个核心创新模块：针对血管不连续，我们引入了块信息增强模块（PIE），它取代了标准的跳跃连接来执行逐块注意力。为减少细节丢失，我们提出了多尺度特征融合模块（MFF），通过从原始输入和前一层提取视觉可解释的特征，为PIE模块提供丰富的多尺度信息。最后，连通性细化解码器（CRD）旨在细化来自各个层级的特征，并在最后的卷积层使用大卷积核以减少碎片化。在三个公共数据集（OCTA-500、ROSE-1和ROSSA）上的实验表明，我们提出的LSENet在参数更少的情况下实现了最先进的性能。

## Abstract
Existing deep learning frameworks for Optical Coherence Tomography Angiography (OCTA) vessel segmentation are largely derived from the U-Net architecture, which serves as the foundation for most current designs. However, most of these methods focus only on holistic representation, struggling to address the problem of low local contrast unique to OCTA, which leads to vessel discontinuities and loss of detail. To address these problems, we propose LSENet, which builds upon the U-Net architecture by introducing three core innovative modules: To address vessel discontinuities, we introduce the Patch Information Enhance module (PIE), which replaces standard skip connections to execute patch-wise attention. To mitigate detail loss, the Multiscale Feature Fusion module (MFF) is proposed to feed the PIE module rich, multi-scale information by extracting visually interpretable features from both the original input and preceding layers. Finally, the Connectivity Refinement Decoder (CRD) is designed to refine features from all levels and utilize a large kernel in the final convolutional layer to reduce fragmentation. Experiments on three public datasets (OCTA-500, ROSE-1, and ROSSA) demonstrate that our proposed LSENet achieves state-of-the-art performance while requiring fewer parameters.

### 1. 论文的核心问题与整体含义（研究动机和背景）
- **研究领域**：光学相干断层扫描血管成像（OCTA）视网膜血管分割。
- **核心问题**：现有深度学习方法（多基于U‑Net架构）主要依赖**整体表示（holistic representation）**，即对全局特征进行“一瞥”，但这种范式难以应对OCTA图像独特的**低局部对比度（low local contrast）**。
- **具体表现**：在微血管、血管边缘及末梢等区域，血管与背景的区分度极低，导致分割结果出现**血管不连续、细节丢失**。
- **研究目标**：提出一种**局部敏感增强网络（LSENet）**，通过放大局部区域内的多尺度特征信息，使模型能够“凝视细节（gaze into details）”，从而在保持轻量化的同时解决上述问题。

### 2. 论文提出的方法论
LSENet 基于轻量 U‑Net（通道固定为64），通过三个核心模块实现局部敏感增强：

- **块信息增强模块（PIE）**  
  - 替代标准跳跃连接，将特征图划分为若干个非重叠的小块（patch），在局部区域内执行**块级注意力**，避免全局前景/背景极端值的干扰。  
  - 包含两个分支：  
    - **块内注意力（Intra‑Patch Attention）**：每个块内独立计算自注意力（使用5×5卷积生成Q/K，1×1卷积生成V，并加入相对位置编码）。  
    - **偏移块内注意力（Shifted Intra‑Patch Attention）**：在输入上填充 P/2 后分区，输出裁剪回原尺寸，解决固定边界切断连续血管的问题（可实现2倍有效感受野）。  
  - **块间注意力（Inter‑Patch Attention）**：对每个块进行空间平均池化，得到 N 个 token，然后执行标准的多头注意力，捕获全局上下文。  
  - 最终特征由三分支结果求和、ReLU激活和残差连接得到。

- **多尺度特征融合模块（MFF）**  
  - 为 PIE 提供丰富的多尺度血管细节。  
  - 输入包括：从上一 MFF 层输出的 `X_down` 和经过平均池化的原始图像 `X_in`（保持视觉可解释性）。  
  - `X_in` 先经 3×3 卷积块，再并联 1×1、3×3、5×5 卷积块提取多尺度特征，经**通道注意力（CA）**筛选后与 `X_down` 拼接，再通过 1×1 和 3×3 卷积融合。

- **连通性细化解码器（CRD）**  
  - 用于细化特征并保持血管连通性。  
  - 在解码器每个阶段，将上采样特征与对应 PIE 特征拼接后经 1×1 卷积块，再通过两个 3×3 卷积块得到输出。  
  - 关键设计：**将最终输出层由标准的 1×1 卷积替换为 11×11 大卷积核（无偏置）**，利用更大的感受野抑制碎片化假阳性，提升血管连续性。

- **损失函数**：联合二进制交叉熵损失（BCE）和 Dice 损失。
