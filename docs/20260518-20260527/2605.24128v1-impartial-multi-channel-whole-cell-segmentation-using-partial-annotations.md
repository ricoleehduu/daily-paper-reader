## 摘要
病理图像中的精确细胞分割通常需要密集的逐像素标注，获取这些标注既昂贵又耗时。这一问题对于新兴的生物成像模态和通道配置多变的多重数据集尤为重要，因为专家标注的数据十分稀缺。在本工作中，我们引入了 ImPartial，一个深度学习框架，旨在使用稀疏涂鸦和有限监督，在低标注条件下实现最先进的分割性能。ImPartial 通过自监督的多通道量化插补增强了分割目标。该方法基于如下观察：精确的图像像素级重建或去噪并非实现精确分割所必需，因此引入了一个与整体分割目标更契合的自监督分类目标。我们证明，ImPartial 在显著减少标注量的情况下，达到了与全监督模型相当的性能。在基准多重细胞成像和单重临床明场免疫组织化学数据集上的大量实验表明，仅使用部分标注，该方法就比强基线方法有了一致的提升。所有基准数据集和代码均可通过我们的 Github 获取：https://github.com/nadeemlab/ImPartial。

## Abstract
Accurate cell segmentation in pathology images typically requires dense pixel-wise annotations, which are costly and time-consuming to obtain. This challenge is especially important for emerging biological imaging modalities and multiplexed datasets with variable channel configurations, where expert-labeled data are scarce. In this work, we introduce ImPartial, a deep learning framework designed to achieve state-of-the-art segmentation performance in low-annotation regimes using sparse scribbles and limited supervision. ImPartial augments the segmentation objective via self-supervised multi-channel quantized imputation. This approach leverages the observation that perfect pixel-wise reconstruction or denoising of the image is not needed for accurate segmentation, and thus, introduces a self-supervised classification objective that better aligns with the overall segmentation goal. We demonstrate that ImPartial achieves performance at par with fully supervised models while requiring substantially fewer annotations. Extensive experiments on benchmark multiplexed cellular imaging and single-plex clinical brightfield immunohistochemistry datasets show consistent improvements over strong baselines with only partial annotations. All benchmark datasets and code are available via our Github: https://github.com/nadeemlab/ImPartial.

### 2. 论文提出的方法论
- **核心思想**：将图像分割与一个自监督的分类目标结合，假定图像中前景和背景的像素强度可分别由少量单峰分布（高斯混合成分）近似，从而将去噪重建转化为对混合成分的归属预测，并使该预测与涂鸦提供的弱监督对齐，形成“去噪与分割协同”的训练范式。
- **关键技术细节**：
  - **盲点网络（Blind‑Spot Network）**：借鉴 Noise2Void，对每个训练块随机替换一部分像素（概率 0.2）为邻域随机值，生成盲点补丁 \(\bar{\mathbf{x}}^b\)，迫使网络依据局部上下文预测原始被替换像素的值。
  - **混合模型重建损失（\(\mathcal{L}_{\text{mix}}\)）**：使用 U‑Net 同时输出每个像素的组件归属概率 \(\rho_m^\theta(\cdot)\) 和各组件的分布参数（此处用固定方差高斯，仅预测均值 \(\tau_m^{\theta'}(\cdot)\)）。将背景和前景分为两类（\(k=0,1\)），每类含 \(m_k\) 个分量（实验中 \(M=4\)，各 2 个）。损失仅在盲点像素上计算，形式为对数似然的加权和：\(\ell_{\text{mix}}(x^b_i;\bar{\mathbf{x}}^b,\Theta)=\sum_m \rho_{m,\theta,i}(\bar{\mathbf{x}}^b)\ln p(x^b_i|\tau_{m,\theta',i}(\bar{\mathbf{x}}^b))\)。该目标鼓励网络将像素分配到能较好重建其原始强度的成分，不追求完美的像素级去噪，而是形成一种“量化插补”。
  - **涂鸦损失（\(\mathcal{L}_{\text{seg}}\)）**：对于涂鸦中标注为 \(k=0\) 或 \(k=1\) 的像素，计算类别平衡的交叉熵损失，其中类别概率为该类所有分量的归属概率之和。即 \(\ell_{\text{seg}}^k=-\sum_{i\in S^{b,k}}\log\!\Big(\sum_{m\in m_k}\rho_{m,\theta,i}(\bar{\mathbf{x}}^b)\Big)\)，并按类内涂鸦数量归一化。
  - **联合损失**：\(\min_\Theta\sum_{k\in\{0,1\}}(1-\lambda)\mathcal{L}_{\text{seg}}^k+\lambda\mathcal{L}_{\text{mix}}\)，超参数 \(\lambda\) 控制两项之间的权重。
  - **多通道扩展**：混合分量的均值变为通道维向量 \(\tau_m\in\mathbb{R}^C\)（固定方差），归属概率在所有通道间共享，涂鸦损失同样基于前景分量之和计算，公式无需改变。
  - **训练配置**：U‑Net（深 4，初始特征图 64，核大小 3），随机切取 128×128 块，批大小 64，训练 200 轮，Adam 优化器（学习率 \(4\times10^{-4}\)），验证基于联合损失。
