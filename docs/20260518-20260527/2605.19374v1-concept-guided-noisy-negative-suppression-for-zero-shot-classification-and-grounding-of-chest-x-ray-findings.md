## 摘要
利用胸部X射线和放射学报告进行视觉-语言对齐已成为胸部X射线发现零样本分类与定位的一种先进范式。然而，标准的对比学习通常简单地将不同患者的放射影像和报告视为负样本对。这一假设引入了噪声负样本，因为不同患者经常表现出相似的发现。此类噪声负样本导致语义歧义，并降低了零样本理解任务的性能。为了解决这一挑战，我们提出了CoNNS，一个概念引导的噪声负样本抑制框架。为了支持负样本抑制机制，与以往使用原始报告或模板化文本的方法不同，我们利用大型语言模型构建了一个层次概念本体。该本体通过显式建模存在性、属性（位置和特征）和文本（证据片段和存在性陈述），结构化了41个关键临床概念。基于这一本体，我们实施了一种跨患者对重新标记策略，包括三个步骤：（1）细粒度分解，根据发现的存在性对成对样本进行分类；（2）噪声负样本过滤，通过去除假负样本来解决语义冲突；以及（3）难负样本挖掘，利用轻量级语言模型识别细微的属性差异。最后，我们提出了一种概念感知的NCE损失，在将视觉特征与文本对齐的同时，抑制已识别的噪声负样本。在多粒度零样本定位任务和五个零样本分类数据集上的大量实验验证了CoNNS优于现有最先进模型。代码可在https://github.com/DopamineLcy/conns获取。

## Abstract
Vision-language alignment using chest X-rays and radiology reports has emerged as an advanced paradigm for zero-shot classification and grounding of chest X-ray findings. However, standard contrastive learning typically treats radiographs and reports from different patients simply as negative pairs. This assumption introduces noisy negatives, as different patients frequently exhibit similar findings. Such noisy negatives cause semantic ambiguity and degrade performance in zero-shot understanding tasks. To address this challenge, we propose CoNNS, a concept-guided noisy-negative suppression framework. To support the negative suppression mechanism, unlike previous methods that use raw reports or templatized texts, we construct a hierarchical concept ontology using large language models. The ontology structures 41 key clinical concepts by explicitly modeling presence, attributes (location and characteristics), and texts (evidential segment and presence statement). Leveraging this ontology, we implement a cross-patient pair relabeling strategy comprising three steps: (1) Fine-Grained Breakdown to categorize pairs based on finding presence; (2) Noisy Negative Filtering to resolve semantic conflicts by removing false negatives; and (3) Hard Negative Mining to identify subtle attribute discrepancies using a lightweight language model. Finally, we propose a Concept-Aware NCE loss to align visual features with text while suppressing the identified noisy negatives. Extensive experiments across multi-granularity zero-shot grounding tasks and five zero-shot classification datasets validate that CoNNS outperforms existing state-of-the-art models. The code is available at https://github.com/DopamineLcy/conns.

## 1. 论文的核心问题与整体含义
- **研究背景**：在胸部X光（CXR）的视觉-语言对齐中，利用图文对比学习可实现零样本分类与定位，无需昂贵的边界框或类别标注。
- **核心问题**：标准的对比学习（如CLIP式）将不同患者的影像-文本对一律视为负样本。但在放射学数据中，不同患者常出现相同发现（如“心脏肥大”），这种“噪声负样本”会导致模型被强迫推远语义一致的图文对，引入矛盾监督信号，造成语义歧义，严重损害零样本理解性能。
- **论文整体含义**：提出 **CoNNS（Concept-Guided Noisy Negative Suppression）** 框架，通过构建层次化概念本体，对跨患者图文对进行精细重标记，以此识别并抑制噪声负样本，从而在零样本分类与定位任务上取得显著提升。

## 2. 论文提出的方法论
### 2.1 核心思想
- 将对比学习的负样本定义从**患者级别**转向**概念级别**：不同患者若共享临床发现则不应被强制推远，而属性（位置、特征）冲突的图像对应被保留为难负样本。
- 构建**层次化概念本体**，从报告中抽取结构化信息，同时保留临床语言多样性与提示一致性，支撑后续重标记与损失计算。

### 2.2 关键技术细节
#### 阶段1：层次化概念本体构建（基于LLM）
- 使用本地部署的 **Llama-3.3-70B-Instruct**，从MIMIC-CXR报告中为 41 个关键临床概念提取信息。
- 每个概念本体分为三个层级：
  - **Presence**（Yes / No / Unk）
  - **Attributes**（Location、Characteristics）
  - **Texts**（Evidential segment 保留语言多样性；Presence statement 保证提示一致性，训练时各以 50% 概率采样）

#### 阶段2：跨患者对重标记（构建关系矩阵 \(M\)）
基于概念本体，为每对图文生成 \(M_{i,j} \in \{1, 0, \varnothing\}\)（正样本/负样本/忽略），包含三步：
1. **细粒度分解（Fine-Grained Breakdown）**：根据 Presence 状态构建 `3×3` 网格（Yes/No/Unk × Yes/No/Unk）。
2. **噪声负样本过滤**：
   - **No-No** 对 → 正样本 (\(M=1\))
   - **Yes-No** 对 → 负样本 (\(M=0\))
   - 含 **Unknown** 的对 → 忽略 (\(M=\varnothing\))
   - **Yes-Yes** 对 → 待定（交由硬负挖掘）
3. **难负样本挖掘（Hard Negative Mining）**：
   - 对 Yes-Yes 对，利用轻量模型 **nli-deberta-v3-small** 比较 Location 与 Characteristics。
   - 若属性明确矛盾（如 Left vs. Right） → 标记为硬负样本 (\(M=0\))
   - 若属性相似或无法区分 → 视为潜在噪声负样本而忽略 (\(M=\varnothing\))

#### 阶段3：概念感知 NCE 损失（CA-NCE Loss）与视觉-语言对齐
- **输入**：图像编码器（冻结的 Rad-DINO-Maira-2 + 2 层可训练 ViT，输入 518×518）；文本编码器（BiomedVLP-CXR-BERT，128 token）。
- **相似度计算**：计算文本 token 与图像 patch 的点积相似度，经 softmax 归一化得到注意力权重，聚合成概念特定的视觉表示 \(\hat{v}_{i,j}\)，再与文本嵌入对齐。
- **损失函数**：基于 InfoNCE 扩展，利用重标记矩阵 \(M\) 生成二元掩码 \(M_{\text{pos}}\)（正样本）与 \(M_{\text{valid}}\)（参与损失的有效对），定义 Text-to-Image 和 Image-to-Text 损失，仅将正样本拉近，并在分母中忽略噪声负样本（\(\varnothing\)）。最终损失为有效正样本的平均。
- **反事实提示（Counterfactual Prompting）**：为增强负样本多样性，从 Presence 相反的患者中采样描述，并将其属性置空，以避免虚假相关。
