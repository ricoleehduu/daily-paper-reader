## 摘要
冷启动主动学习（CSAL）对于在低标注预算下通过从未标注训练集中查询少量子集进行标注来提升医学图像分割模型性能具有重要意义。现有CSAL方法通常依赖低效的、数据集特定的自监督学习（SSL）将未标注图像映射到特征空间以进行样本选择。近年来，分割一切模型（SAM）等基础模型的出现提供了一种有前景的替代方案，因为预训练模型能够提供强泛化性的特征嵌入，并在微调（自适应）后在下游任务中取得高性能。然而，在低标注预算的自适应过程中如何系统利用SAM的固有嵌入进行冷启动样本选择仍未得到充分探索。为此，我们提出一种扩展的基于SAM的不确定性引导特征加权（SUGFW+）框架，用于CSAL和SAM自适应。具体而言，该方法利用SAM进行块级特征与不确定性计算（PFUC），并引入基于块的全局判别表示（PGDR）模块，将块级嵌入聚合为高判别性、不确定性感知的图像级特征。随后，这些特征被用于通过带聚类和不确定性的贪心选择（GSCU）策略在样本选择中结合多样性与不确定性。与以往将样本选择与模型训练解耦的CSAL方法不同，SUGFW+通过模型训练中SAM的不确定性提示微调（UPFT）过程将这两个阶段紧密集成。在四个公开数据集上的大量实验表明，SUGFW+相较于现有CSAL方法达到了最先进的性能。代码见 https://github.com/HiLab-git/SUGFW-plus。

## Abstract
Cold Start Active Learning (CSAL) is important in improving the performance of a medical image segmentation model with low annotation budget by querying a small subset for annotation from an unlabeled training set. Existing CSAL methods typically rely on inefficient dataset-specific Self-Supervised Learning (SSL) to map the unlabeled images into a feature space for sample selection. Recently, the advent of foundation models such as the Segment Anything Model (SAM) offer a promising alternative as the pre-trained model can provide strong generalizable feature embeddings, and allow high performance in downstream tasks after fine-tuning (adaptation). However, how to systematically exploit SAM's inherent embeddings for cold-start sample selection during adaptation with low annotation budget remains underexplored. To address this, we propose an extended SAM-based Uncertainty-guided Feature Weighting (SUGFW+) framework for CSAL and adaptation of SAM. Specifically, it leverages the SAM for Patch-level Feature and Uncertainty Calculation (PFUC), and introduces a Patch-based Global Distinct Representation (PGDR) module that aggregates patch-level embeddings into highly discriminative, uncertainty-aware image-level features. These features are then utilized by a Greedy Selection with Cluster and Uncertainty (GSCU) strategy to combine diversity and uncertainty during sample selection. Unlike prior CSAL methods that decouple sample selection from model training, SUGFW+ tightly integrates these two stages via an Uncertainty-Prompted Fine-Tuning (UPFT) process of SAM in model training. Extensive experiments on four public datasets demonstrate that SUGFW+ achieves state-of-the-art performance against existing CSAL methods. Code is available at https://github.com/HiLab-git/SUGFW-plus.

- **研究背景**：医学图像分割需要像素级密集标注，获取成本高、耗时长。主动学习（AL）能通过选择信息量大的样本减少标注预算，但传统 AL 通常需要初始标注集并依赖多轮查询，难以直接用于完全无标签的冷启动场景。

- **整体含义**：论文提出 SUGFW+ 框架，将 SAM 同时用于样本查询和下游模型训练，通过不确定性引导的特征加权、贪心聚类选择以及不确定性提示微调，实现低标注预算下的高性能医学图像分割。

## 2. 论文提出的方法论

- **框架总览**：SUGFW+ 包含两个紧密耦合的阶段：① SUGFW（基于 SAM 的不确定性引导特征加权）用于从无标签数据集中选择查询样本；② UPFT（不确定性提示微调）用于使用所选少量标注样本微调 SAM。
- **SUGFW 样本选择阶段**：
  - **PFUC（Patch-level Feature and Uncertainty Calculation）**：
    - 使用 SAM 图像编码器 \(E_{\text{img}}\) 提取块级特征图 \(F_i\)。
    - 利用 SAM 的 “everything mode” 生成类无关分割掩码，并通过 K 次数据增强得到平均软掩码。
    - 对软掩码逐块计算熵，得到代理不确定性图 \(U_i\)。
  - **PGDR（Patch-based Global Distinct Representation）**：
    - 以不确定性为权重，对块级特征进行 softmax 加权求和，得到不确定性感知的图像级全局特征 \(f_i\)。
    - 同时将不确定性图平均池化为图像级不确定性分数 \(u_i\)。
  - **GSCU（Greedy Selection with Cluster and Uncertainty）**：
    - 对图像级特征 \(f_i\) 进行 K-means 聚类，聚类数等于标注预算 \(M\)。
    - 从每个簇中选择一个样本：首个样本选自随机簇中不确定性分数的中位数；后续样本从新簇中贪心选择，最大化与已选样本不确定性分数的最小距离，从而同时兼顾特征空间代表性和不确定性空间多样性。
- **UPFT 微调阶段**：
  - 使用代理不确定性图 \(U_i\) 作为空间提示，替代 SAM 原有的提示编码器，通过不确定性编码器 \(E_{\text{un}}\) 生成不确定性嵌入 \(F_i^u\)，注入 mask decoder 的交叉注意力中。
  - 为降低推理时多次前向计算不确定性的开销，引入轻量不确定性预测器 \(g(\cdot)\)，从特征图 \(F_i\) 和平均不确定性图直接估计不确定性嵌入，并用 MSE 损失训练。
  - 总损失函数：\(L = \omega L_{\text{Dice}} + (1-\omega) L_{\text{CE}} + \alpha_t L_u\)，其中 \(\alpha_t\) 采用 ramp-up 策略。
  - 训练时冻结 SAM 图像编码器并加入 LoRA 层，更新 LoRA、mask decoder、不确定性编码器和不确定性预测器；推理时用预测器 \(g\) 替代不确定性编码器。

## 9. 总结与展望

- **实际意义**：该方法为医学图像分割中的冷启动主动学习提供了新思路，在无需任何初始标注的情况下即可用极低标注预算达到接近或超过全监督模型的性能，具有较高的临床转化潜力。
- **未来方向**：
