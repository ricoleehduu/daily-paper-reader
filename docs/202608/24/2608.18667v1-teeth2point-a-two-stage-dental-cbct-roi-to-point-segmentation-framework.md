## 摘要
现代深度学习架构已在牙科 CBCT 分割中表现出强大性能。一个仍然关键挑战是在牙齿缺失或错位的情况下准确标记牙齿，这对牙科临床实践非常重要。基于 Transformer 的架构理论上应能利用全局解剖上下文来解决此类歧义。然而，由于 CBCT 体积的高分辨率以及牙齿在体积内广泛的空间分布，基于密集块的体积处理面临固有的权衡。计算成本限制了可在自注意力中使用的块数量，因此要么扩大自注意力捕获的上下文范围，要么使用小块捕获细粒度结构细节，二者不可兼得。本文提出 Teeth2Point，一种用于牙科 CBCT 语义分割的高效基于点的 Transformer 框架，可避免这一权衡。Teeth2Point 首先使用卷积模型定位牙齿周围的体积感兴趣区域（ROI），然后通过自适应采样将 ROI 转换为点 token。Transformer 模型利用点 token 预测准确分割，从而在保留高分辨率的同时捕获全局上下文。该 Transformer 首先采用自监督学习（SSL）进行预训练，方式类似 DINO，但使用领域特定的增强策略，然后进行监督微调。包含随机 token 掩码的 SSL 预训练为复杂解剖变异提供了鲁棒性。与最强的两阶段基线相比，Teeth2Point 在四个数据集上平均将异常病例性能提高了 1.44 个 DSC 点；相对于第一阶段 nnU-Net，增益为 1.9 个点。

## Abstract
Modern deep learning architectures have demonstrated strong performance in dental CBCT segmentation. One remaining crucial challenge is accurate tooth labeling in cases with missing or malpositioned teeth, which are highly relevant for dental practice. Transformer-based architectures should in theory be able to resolve such ambiguities using global anatomical context. However, due to the high resolution of CBCT volumes and the wide spatial distribution of teeth within volumes, dense patch-based volumetric processing faces an inherent trade-off. Computational costs limit the number of patches that can be used in self-attention and thus, one can either increase the extent of the context captured in self-attention or capture fine-grained structural details by using small patches, but not both. In this work, we present Teeth2Point, an efficient point-based transformer framework for dental CBCT semantic segmentation that can avoid this trade-off. Teeth2Point first localizes volumetric regions of interest (ROIs) surrounding teeth using a convolutional model, then converts ROIs into point tokens using adaptive sampling. A transformer model predicts accurate segmentations using the point tokens, which allow capturing global context while retaining high resolution. The transformer is first pretrained using self-supervised learning (SSL), in the style of DINO but using domain-specific augmentation strategies, followed by supervised finetuning. The SSL pretraining, which includes random token masking, provides robustness to complex anatomical variations. Compared with the strongest two-stage baseline, Teeth2Point improves abnormal-case performance by 1.44 DSC points on average across four datasets; relative to the first-stage nnU-Net, the gain is 1.9 points.

## 1. 论文的核心问题与整体含义

- **研究背景**：牙科锥形束 CT（CBCT）三维分割在临床定量分析和治疗规划中至关重要。现代深度学习模型在该任务上表现良好，但在**牙齿缺失或错位**等异常情况下，准确的实例级牙齿标注仍是一大挑战。
- **核心矛盾**：Transformer 架构理论上能利用全局解剖上下文（如左右对称、上下牙弓关系）解决歧义，但 CBCT 体积分辨率高、牙齿空间分布稀疏（前景占比低至 0.5%），导致**密集 patch 处理存在上下文范围与细节保留之间的本质权衡**——要么扩大自注意力上下文而丢失细节，要么使用小块保留细节但上下文不足。
- **整体含义**：作者提出 **Teeth2Point**，一种两阶段 **ROI-to-Point（感兴趣区域到点云）** 分割框架，用稀疏点表示替代密集体素表示，从而在保留高分辨率表面细节的同时，使 Transformer 能高效建模全局解剖上下文，提升异常病例的分割鲁棒性。

## 2. 论文提出的方法论

### 2.1 总体两阶段流程
- **第一阶段：ROI 体积提取**  
  - 使用卷积分割模型（如 nnU-Net）对完整 CBCT 体积 `V` 做滑动窗口推理，得到各牙齿类别和背景的 logits。
  - 通过 argmax 获得体素级预测，提取所有牙齿前景掩码 `M`。
  - 对前景掩码进行 **3D 膨胀**（6-连通核，膨胀约 0.3 mm）得到增强掩码 `M_aug`，避免遗漏结构。
- **第二阶段：ROI 点云分割**  
  - 收集增强掩码内的所有体素，构建点集 `X`。每个点 `x_i` 包含：
    - 体素坐标 `c_i ∈ R³`
    - 归一化强度 `I_i`（CBCT 强度裁剪至 [−1000, 3512] 后做 z-score 标准化）
    - 强度梯度向量 `g_i`
  - 点集经自适应采样后输入点 Transformer，输出点级预测。
  - 使用 KNN（K=4）插值将预测传播到未采样点，再体素化并与第一阶段背景合并，得到最终体积分割。

### 2.2 梯度引导自适应采样（GGAS）
- 动机：牙齿判别线索主要位于结构边界附近，均匀采样效率低。
- 方法：
  - 计算所有点的梯度幅值 `|g_i|` 并做 min-max 归一化。
  - 构建粗网格，每个单元包含 `ε³` 个体素（ε=2）。
  - 在每个单元内构建梯度幅值直方图（固定 bin 宽 α=0.125）。
  - 从每个非空 bin 中按与 `|g_i|` 成比例的概率采样一个点。
- 效果：高梯度变化区域获得更多采样点，均匀区域仅保留少量点，实现**表面聚焦**的点表示。

### 2.3 点 Transformer 架构
- 点属性经线性嵌入层转为点 token。
- 采用 encoder–decoder 主干网络，包含：
  - 空间池化（每个体素内最大特征池化）
  - 反池化（最近邻插值）
  - 跳跃连接实现多级特征融合。
- 输出点级语义分割概率。

### 2.4 自监督预训练（DINOv2 风格）
- **网络结构**：学生网络 `θ_s` 学习匹配指数滑动平均（EMA）教师网络 `θ_t` 的输出。
- **视图构建**：
  - 对点集 `X` 生成局部视图 `X_l` 和全局视图 `X_g`，使用强度变换、随机旋转、弹性形变。
  - 若未使用自适应采样，额外采用球邻域裁剪（局部视图比例 0.1–0.4，全局视图 0.4–1.0）。
- **点级蒸馏**：
  - 教师编码全局视图得到特征 `F_g`，学生编码局部视图得到 `F_l`。
  - 将每个 `F_l` 点特征与其在 `F_g` 中的最近邻配对，转化为概率后计算 KL 散度。
  - 使用 Sinkhorn-Knopp 中心和聚类分配归一化防止表征坍缩。
- **随机 token 掩码**：
  - 构造掩码全局视图 `X_mg`，随机掩码点，训练调度掩码比例从 0.3 增至 0.7。
  - 学生嵌入掩码点并预测被掩码位置的特征，最小化 `F_g` 与 `F_mg` 的差异。
- **牙科领域增强**：
  - 强度变换（伽马校正、亮度缩放）。
  - **对称增强**：翻转点并重映射标签，利用双侧牙齿结构。
  - **伪影增强**：模拟金属引起的条纹伪影，随机选择牙齿类别放大其点强度。

### 2.5 渐进式监督微调
- 第一阶段（GT-ROI）：在标注的真实前景点上训练，损失为 Dice + 交叉熵（等权重）。
- 第二阶段（预测 ROI 适应）：输入来自第一阶段预测 ROI，可能包含背景或不完整结构，用对应体素标签继续微调，提升对预测 ROI 误差的鲁棒性。

## 6. 论文的主要结论与发现

- **性能提升**：Teeth2Point 在四个数据集上的平均异常病例 DSC（DSC-A）达到 **93.70**，比最强两阶段基线（ROI 裁剪 nnU-Net，92.26）提高 **1.44 个 DSC 点**；相对于第一阶段 nnU-Net（91.82）提高 **1.9 个点**。
- **常规-异常差距缩小**：与第一阶段 nnU-Net 相比，Teeth2Point 在常规病例 DSC-R 上提高 0.6 点，异常病例 DSC-A 上提高 1.9 点，将常规-异常性能差距缩小约 **26%**。
- **全局上下文捕获**：预训练表征的可视化显示模型捕捉到明显的左右对称（PCA 特征 1–3）和上下颌结构关系（特征 4–6），注意力图显示磨牙区域 token 会关注水平与垂直方向的对应解剖位置。
- **计算效率**：点阶段推理仅需 0.9 秒，完整流程约 13.7 秒，相比全体积 Transformer 方法（如 VideoTeeth 51.2 秒）显著高效。
- **标签效率**：自监督预训练大幅降低标注需求，10 个标注样本即可达到 86.7 DSC。
- **局限性结论**：框架非端到端，若第一阶段 ROI 提取完全漏检牙齿，第二阶段无法恢复。

## 7. 优点

- **巧妙的表示选择**：将稀疏牙齿 ROI 转换为点云，利用点表示天然聚焦前景结构，避免了密集体素表示中背景占主导的问题，同时保留高分辨率表面细节。
- **自适应采样策略**：GGAS 依据梯度分布分配采样点，在边界等判别区域增加密度，提升采样效率和信息保留。
- **领域定制的自监督预训练**：将 DINOv2 扩展到 3D 点云，并引入牙科特有的对称增强和金属伪影增强，使预训练表征更适合 CBCT 解剖结构。
- **渐进式微调**：先 GT-ROI 后预测 ROI 的适应策略，有效缓解了训练与推理阶段 ROI 分布不一致的问题。
- **全面的对比与评估**：在四个数据集、多种异常比例下与 8 种方法对比，且单独报告异常病例 DSC，突出了方法在困难场景下的优势。
- **高效推理**：点阶段推理极快，具备临床实时应用的潜力。

## 8. 不足与局限

- **非端到端依赖**：框架依赖独立的第一阶段卷积模型提取 ROI，若该阶段漏检牙齿（特别是小牙齿或严重异常），错误无法被第二阶段纠正，形成误差传播。
- **实验统计可靠性不足**：仅使用单一 70/30 划分，缺乏交叉验证、多次重复或置信区间，作者也承认结果是描述性的，尚不能进行严格推断。
- **缺少外部验证**：未能提交官方 Grand Challenge 排行榜，无法在真正的独立测试集上验证性能。
- **点表示可能丢失体素上下文**：将体素转换为稀疏点虽然高效，但可能丢失局部体积纹理信息；虽然梯度特征部分补偿，但其影响未单独量化。
